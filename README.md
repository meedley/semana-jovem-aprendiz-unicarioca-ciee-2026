# 🧠 Minha Lista Inteligente

Uma aplicação web simples construída com React para organizar tarefas do dia a dia.

👉 Projeto desenvolvido com foco em aprendizado de desenvolvimento web moderno.

## 🎯 Objetivo

Este projeto tem como objetivo:

- aprender os fundamentos de aplicações web
- entender o funcionamento do React
- praticar organização de código
- simular o início de um produto digital (mini SaaS)

---

## 🧩 Funcionalidades

- adicionar tarefas
- marcar tarefas como concluídas
- remover tarefas
- validação de entrada (não permite tarefas vazias)
- persistência no navegador (localStorage)
- interface moderna e responsiva

---

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- React (via CDN)
- Babel (para JSX)

---

## 🧠 Conceitos aplicados

- Componentes React
- useState (estado)
- useEffect (persistência)
- Manipulação de listas
- Eventos (onClick, onChange)
- Estruturação de interface

---

## 🔐 Segurança básica

Este projeto aplica conceitos iniciais de segurança:

- validação de entrada do usuário
- não utilização de dados sensíveis
- execução apenas no frontend (sem backend exposto)

---

## ⚠️ Limitações

- não possui login de usuário
- não possui banco de dados real
- não possui backend
- não possui sistema de monetização

👉 Este é um MVP (Minimum Viable Product)

---

## 💡 Possíveis melhorias

- autenticação de usuários
- integração com banco de dados (Firebase ou Supabase)
- criação de categorias de tarefas
- compartilhamento de tarefas
- plano gratuito vs plano pago

---

## 💸 Ideia de monetização (SaaS)

Este projeto poderia evoluir para um produto com:

- plano gratuito limitado
- plano Pro com funcionalidades extras
- sincronização na nuvem
- lembretes inteligentes
